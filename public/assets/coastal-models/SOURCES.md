# CC0 coastal model sources

All files below are from Poly Haven under [CC0](https://polyhaven.com/license), which permits redistribution and commercial use. These are the 1K glTF variants plus separate alpha masks for cutout plants. Each local file was verified against the MD5 supplied by the Poly Haven files API at download time. The game modifies placement, orientation, tint, alpha handling, and wind animation; original source files remain unmodified.
