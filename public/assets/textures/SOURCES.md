# Terrain texture sources

The following nine JPG maps (six at 1K and three at 2K) were downloaded from Poly Haven's official CDN. Poly Haven publishes these assets under CC0; attribution is optional. The files are included locally so the game can run without a texture network request to a third party.

License: https://polyhaven.com/license

Asset page: https://polyhaven.com/a/rock_face
