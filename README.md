# IslandWorld

> A procedural coastal island world built with Three.js and Blender assets.

Procedurally generates a coastal island — terrain, vegetation, buildings,
and dynamic weather — entirely in the browser.

## 🛠️ Tech

- **Three.js** — 3D rendering
- **Blender** — building models (lodge, archive, radio house, signal tower)
- **Procedural generation** — terrain, vegetation placement, paths

## 🎯 Use Cases

- Game environments
- Portfolio pieces
- 3D web experiences
- Learning procedural generation
